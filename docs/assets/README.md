# Referenzdokumente

Offizielle Spiel- und Wettbewerbsdokumente, gegen die Score-Sheet-Vorlagen, Tie-Breaker, Formel-Vorlagen und Tests geprüft werden. Alle Dateien sind öffentliche Downloads der Veranstalter; sie liegen hier unverändert als Referenz. Urheber sind KISS Institute for Practical Robotics (KIPR: Game Review, Score Sheet, Scoring Examples, Dokumentations-Bewertungsbögen) und ERAA – Educational Robotics Association Austria, Veranstalterin der ECER (ECER Amendments, Call for Papers, Aerial-Regelwerk, Ergebnisse). Weitergabe nur zusammen mit dieser Quellenangabe; maßgeblich ist immer die aktuelle Fassung auf der Veranstalter-Seite.
